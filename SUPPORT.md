# Support

## English

- Use the [bug report template](https://github.com/zybless/JimiDeck/issues/new?template=bug_report.yml) for reproducible defects.
- Use the [feature request template](https://github.com/zybless/JimiDeck/issues/new?template=feature_request.yml) for product proposals.
- Use [private vulnerability reporting](SECURITY.md) for security issues.

JimiDeck is maintained as an open-source project and does not currently include a response-time guarantee or paid support plan. Please keep reports concise, redact private data, and include the JimiDeck version and operating system.

## 中文

- 可复现的缺陷请使用[问题报告模板](https://github.com/zybless/JimiDeck/issues/new?template=bug_report.yml)。
- 产品建议请使用[功能建议模板](https://github.com/zybless/JimiDeck/issues/new?template=feature_request.yml)。
- 安全问题请按照[安全策略](SECURITY.md)私密报告。

JimiDeck 目前作为开源项目维护，不承诺响应时限，也暂未提供付费支持。提交问题时请保持简洁，删除私人数据，并注明 JimiDeck 版本与操作系统。
