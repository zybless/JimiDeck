# Changelog

Notable changes are recorded here. The project follows [Semantic Versioning](https://semver.org/) while it remains in active development.

## 0.2.0 - 2026-08-13

### English

- Added safe import of existing macOS `codex-profile` profiles.
- Hardened Windows storage writes, path validation, and build dependencies.
- Added four release formats: macOS DMG and ZIP, Windows installer and portable ZIP.
- Added repository boundary checks and aligned product documentation with current platform support.

### 中文

- 支持安全导入 macOS 上已有的 `codex-profile` 配置。
- 加强 Windows 存储写入、路径校验与构建依赖。
- 提供 macOS DMG、macOS ZIP、Windows 安装包和 Windows 便携包四种发布格式。
- 增加项目边界检查，并让产品文档与当前平台能力保持一致。

## 0.1.0 - 2026-08-13

- Initial alpha release for macOS and Windows.
- 发布首个 macOS 与 Windows Alpha 版本。
