# JimiDeck branding

## Jimi family icon rule

- One product gets one primary app icon; no separate feature-icon set is required.
- Green is the dominant accent color and a cat is the shared family character.
- Green identity shapes and the cat together should occupy no more than about 50% of the composition.
- More than half of the visual weight belongs to the product-specific symbol.
- For JimiDeck, the product symbol is a layered code/terminal deck.
- Keep the silhouette readable at 32 px. Do not use words, letters, watermarks, or third-party trademarks.

## Generated source

`JimiDeck-AppIcon-Source.png` was generated with the built-in image generation tool using the following final direction:

> An ultra-minimal production macOS icon using only a dark rounded-square base, one oversized pair of Jimi-green code brackets, and a tiny flat cream cat silhouette at the lower edge. No windows, lists, code lines, buttons, text, or third-party trademarks.

The production sizes are in `Assets.xcassets/AppIcon.appiconset`.
