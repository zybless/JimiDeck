# Brand assets

`JimiDeck-AppIcon-Source.png` is the high-resolution source for the application icon. Production sizes live in `Assets.xcassets/AppIcon.appiconset`.

The icon combines a dark rounded-square base, green code brackets, and the Jimi cat mark. Keep the silhouette legible at 32 px and do not add text, watermarks, or third-party marks.

The JimiDeck name and logo identify official project releases. See the repository [trademark guidelines](../TRADEMARKS.md) before using them for a modified distribution.
